# Code of Conduct

## Our standard

We are committed to a welcoming, respectful and harassment-free community. Be constructive, assume good intent, respect different backgrounds and experience levels, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, deliberate intimidation, publishing private information, and sustained disruption of project spaces.

## Enforcement

Project maintainers may edit or remove contributions and temporarily or permanently restrict participation when behavior violates this standard. Report conduct concerns privately to the repository owner. Reports will be reviewed confidentially and fairly.

This policy applies in repository discussions, issues, pull requests and other spaces where someone represents the project.
