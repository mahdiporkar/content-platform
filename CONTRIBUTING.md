# Contributing

Thank you for improving Content Platform. Open an issue for substantial changes before implementation and keep pull requests focused.

1. Fork the repository and create a branch from `main`.
2. Copy `.env.example` to `.env`; never commit credentials.
3. Install dependencies in the root and relevant application.
4. Add or update tests and multilingual documentation with behavior changes.
5. Run the affected tests and production builds.
6. Open a pull request using the repository template.

Use clear conventional commit subjects such as `feat(demo): add locale switcher` or `fix(media): preserve referenced assets`.
