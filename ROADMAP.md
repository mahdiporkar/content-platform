# Roadmap

The roadmap describes direction, not guaranteed delivery dates. Proposals and focused pull requests are welcome.

## Current priorities

- Harden and operate isolated public demo workspaces
- Expand automated integration and browser coverage
- Improve bundle splitting and Admin Studio performance
- Add backup, restore and tenant export workflows
- Complete OpenAPI examples and client SDK guidance

## Next

- Webhook delivery with retry and signature verification
- Content revisions, visual diff and rollback
- Translation workflow and locale completeness reporting
- Pluggable storage and CDN providers
- Importers for common CMS export formats

## Later

- GraphQL delivery option
- Workflow approvals and custom editorial states
- Fine-grained field permissions
- Extension and plugin APIs
- Search provider integrations

Track concrete work in [GitHub issues](https://github.com/mahdiporkar/content-platform/issues). Security-sensitive plans belong in private advisories.
